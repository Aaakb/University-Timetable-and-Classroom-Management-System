نظام إدارة الجداول الجامعية — نسخة تتضمن البيانات الحالية

تتضمن هذه الحزمة البرنامج وملفات تشغيل .NET وقاعدة البيانات الحالية، بما فيها الحسابات والمواد والتدريسيون والجداول.

المتطلبات: Windows 10 إصدار 22H2 أو أحدث، أو Windows 11، بنواة 64 بت.
تُضمّن حزم Microsoft SQL Server 2025 LocalDB وMicrosoft Visual C++ الرسمية. إذا لم تكن المتطلبات موجودة، سيطلب Windows صلاحيات مسؤول لتثبيتها. متابعة التثبيت تعني الموافقة على شروط ترخيص Microsoft المرفقة بهذه الحزم.

تُستعاد البيانات في نسخة محلية مستقلة لحساب Windows الذي ينفذ التثبيت. لا يحتاج تشغيل البرنامج بعد ذلك إلى صلاحيات مسؤول أو اتصال بالإنترنت.

لا يستبدل المثبّت قاعدة محلية موجودة من تثبيت سابق. كما لا يحذف إزالةُ البرنامج ملفات قاعدة البيانات الموجودة في مجلد بيانات المستخدم.

يمكن استخدام حسابات الدخول نفسها الموجودة في قاعدة البيانات المرفقة.
لأن الحزمة تحتوي بياناتك، شاركها فقط مع الأشخاص الذين تريد منحهم نسخة من هذه البيانات.

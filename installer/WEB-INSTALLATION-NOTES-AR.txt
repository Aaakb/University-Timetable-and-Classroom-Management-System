نظام الجداول الجامعية - نسخة الويب المحلية

تتضمن الحزمة التطبيق ونسخة من قاعدة البيانات الحالية وحساباتها، مع محرك SQL Server 2025 LocalDB وملفات التشغيل.
تعمل على Windows 10/11 بنواة 64 بت، وتحتاج صلاحية مسؤول لتثبيت متطلبات Microsoft عند غيابها. بعد التثبيت شغّل الاختصار وافتح المتصفح.
تنشأ قاعدة بيانات محلية مستقلة لكل مستخدم Windows ولا تُستبدل قاعدة موجودة عند إعادة التثبيت. تبقى ملفات البيانات عند إزالة البرنامج.
تحتوي الحزمة بيانات خاصة؛ شاركها مع المخولين فقط.

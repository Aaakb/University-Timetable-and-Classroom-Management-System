# تشخيص سعة أيام الدوام عند إنشاء البدائل

اختبار SQL Server معزول ينشئ قاعدة مؤقتة ويحذفها في `finally`. يثبت أن البدائل تشرح اسم التدريسي وعدد المحاضرات والفترات المتاحة عندما تكون أيام الدوام غير كافية، مع استبعاد الاستراحات والفترات ذات المدة غير المناسبة. كما يتحقق من نجاح المعاينة بعد إتاحة يوم إضافي، وعدم حفظ تغييرات أثناء المعاينة، واستقلال الفصل الأول عن تفضيلات الفصل الثاني.

```powershell
dotnet run --project tests/AlternativeAvailability/AlternativeAvailability.csproj
```

النتيجة: 7 تحققات ناجحة. اختبارات التفضيلات والبدائل القائمة في `tests/FacultyPreferences` نجحت أيضًا: 46 تحققًا.

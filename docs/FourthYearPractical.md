# عملي المرحلة الرابعة بدون تقسيمات

جميع تخصصات المرحلة الرابعة تستخدم الشعبة `A` كاملة للنظري والعملي، في الفصلين.
لا تُولَّد مجموعات `A1` أو `A2` للمرحلة الرابعة ولا يقبلها الإدخال اليدوي أو استيراد الجداول.
يمكن إدخال `A` في خانة المجموعة عند الاستيراد، أو تركها فارغة؛ تُحفظ المجموعة فارغة
للدلالة على الشعبة الكاملة، مع احتساب عدد طلبة الشعبة كاملًا عند اختيار المختبر وفحص التعارضات.
تقسيمات المراحل الأخرى تبقى حسب قواعدها.

## تحويل جدول قديم

المعاينة فقط:

```powershell
dotnet run --project tools/FourthYearPractical/FourthYearPractical.csproj
```

التحويل الصريح، على قاعدة الاتصال المضبوطة للتطبيق:

```powershell
dotnet run --project tools/FourthYearPractical/FourthYearPractical.csproj -- --apply
```

تأخذ الأداة نسخة من الجدول قبل التعديل داخل مجلد النسخ التلقائية للمستخدم.
تفضّل المحاضرات المحفوظة للشعبة الكاملة، ثم `A`، ثم `A1`، ثم `A2`،
وتزيل النسخ المقابلة فقط إذا كانت أعداد المحاضرات الأسبوعية متطابقة مع المادة.
لا تُحذف محاضرة مكررة مثبتة. تُفحص السعة والتعارضات قبل إتمام المعاملة؛ الفشل يلغي التعديل كله.
تبقى المواعيد والتدريسيون والقاعات ومعرّفات المحاضرات المحتفظ بها كما هي.
هذا التحويل لا يعمل تلقائيًا عند تشغيل التطبيق.

## التحقق

```powershell
dotnet run --project tests/FourthYearPractical/FourthYearPractical.csproj
```

تعمل الفحوص على قاعدة SQL مستقلة باسم `UniversityTimetable_FourthYear_<random>`،
وتغطي التخصصات الثلاثة والفصلين وتعدد المحاضرات الأسبوعية والأقفال والتراجع عند فشل السعة،
والإدخال والتوليد والواجهة المكتبية وقواعد الويب، مع بقاء مجموعات المراحل الأخرى.

# عرض بيانات تجريبية على Netlify

تعمل هذه الحزمة كواجهة ثابتة على Netlify دون ASP.NET أو SQL Server. تظهر البيانات الافتراضية تلقائيًا: 24 مادة، و8 تدريسيين، و8 شعب، و6 قاعات ومختبرات، و4 مراحل، و3 فروع، و24 تكليفًا، و80 محاضرة موزعة على الفصلين.

## تحديث الرابط الحالي

1. سجّل الدخول إلى Netlify بحساب مالك `scintillating-custard-a1742c`.
2. افتح المشروع ثم **Deploys** واختر الرفع اليدوي، أو اسحب ملف `Netlify-Mock-Demo.zip` إلى منطقة الرفع.
3. انتظر حالة **Published** ثم افتح الرابط الحالي. إذا ظهر إشعار تحديث للتطبيق فاضغط **تحديث التطبيق** ثم أعد تحميل الصفحة.

لا ترفع مجلد المشروع الكامل أو حزمة ASP.NET لهذا العرض. ملف ZIP يحتوي `index.html` في الجذر مباشرة وجميع الأصول اللازمة.

## طبيعة النسخة

كل الأسماء والمحاضرات بيانات افتراضية، ولم تُقرأ أو تُصدّر سجلات الجامعة. تتوفر مشاهدة القوائم والبحث والتصفية والجدول الأسبوعي، وتعديل بيانات العرض والتثبيت محليًا. تُحفظ التغييرات في تخزين المتصفح تحت مفتاح مستقل `university-timetable-demo-v1`؛ لا تُنقل إلى الزوار الآخرين أو SQL Server. زر **إعادة البيانات التجريبية** يعيد المثال الافتراضي بعد التأكيد.

النسخة التجريبية لا تتطلب حسابًا حقيقيًا وتفتح العرض مباشرة. إذا خرجت من العرض، تكفي قيم تجريبية للعودة؛ لا تستخدم كلمة مرور الجامعة.

عُطّلت العمليات التي تحتاج خدمات الخادم، ومنها التوليد والتحسين والاستيراد وتصدير PDF والاستعادة الحقيقية. تعرض صفحات التفضيلات والبدائل بيانات الجدول الحالي فقط؛ لا تدّعي تنفيذ المحسن على المتصفح. العودة إلى الوظائف الكاملة تتطلب استضافة ASP.NET وقاعدة SQL.

## إعادة تجهيز الحزمة والتحقق

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\Build-NetlifyDemo.ps1
node tests/NetlifyDemo/check.mjs
```

يبقى كود نسخة ASP.NET الأصلية دون استبدال. تُنسخ الواجهة إلى مجلد جديد داخل `output`، وتُستبدل طبقة البيانات داخل **حزمة العرض فقط**. فحص المتصفح `tests/NetlifyDemo/browser.mjs` يتطلب خدمة ملفات ثابتة على `http://localhost:5193` ويغطي 22 حالة دون أخطاء JavaScript، مع نتائج وصور في `.tmp/NetlifyDemo`.

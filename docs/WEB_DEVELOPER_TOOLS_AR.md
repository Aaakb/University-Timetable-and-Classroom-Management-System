# أدوات فحص واجهة الويب

لتشغيل الفحوص المحلية من جذر المشروع على Windows، بعد تثبيت .NET SDK وNode.js:

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\Check-Web.ps1
```

يبني الأمر مشروع واجهة البرمجة، ويتحقق من صياغة ملفات JavaScript باستخدام `node --check`، ثم يشغّل برنامج `tests/WebParity`. يتوقف برسالة خطأ عند فشل أي خطوة. يمكن تجاوز بناء واجهة البرمجة المبدئي باستخدام `-SkipBuild`؛ لكن `dotnet run` قد يبني المشاريع المطلوبة للاختبار.

هذه فحوص محلية سريعة، ولا تختبر المظهر أو تفاعل المستخدم في المتصفح. لفحص التكامل الفعلي، راجع [اختبارات واجهة البرمجة والمتصفح](../tests/WebActualApi/README.md): تحتاج إلى SQL Server وصلاحية إنشاء قاعدة اختبار مؤقتة وحذفها، وNode.js وPlaywright وMicrosoft Edge.

للفحص اليدوي، افتح أدوات المطور في المتصفح بمفتاح F12: استخدم Console للأخطاء، وNetwork للطلبات، ووضع الأجهزة لفحص الهاتف. يمكن تشغيل Lighthouse من أدوات المتصفح لتقييم الأداء وإمكانية الوصول، مع مراجعة النتائج يدوياً.

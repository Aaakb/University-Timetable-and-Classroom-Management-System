# إصلاح فشل تصدير PDF — 13 أكتوبر 2026

أُعيد إنتاج الخطأ من ملفات نسخة Release الموجودة في مجلد المشروع الأصلي. فشل RichTextKit أثناء بناء الخطوط بسبب DllNotFoundException عند تحميل `libHarfBuzzSharp.dll`، برسالة Windows `The filename or extension is too long (0x800700CE)`. وقع الفشل قبل كتابة ملف PDF؛ لم يكن اختيار القرص D سبب الخطأ.

عدّل `SchedulePdfExportService` تحميل مكتبات SkiaSharp وHarfBuzz على Windows ليستخدم المسار المطلق بصيغة Windows الممتدة، مرة واحدة لكل عملية. يختار مجلد المكتبة بحسب معمارية العملية x64 أو x86 أو ARM64، ويحتفظ بحلّ المكتبات القياسي للنشر الذي لا يحتوي مجلد runtimes. لا يتطلب نقل المشروع أو تعديل إعدادات Windows. توضح [وثائق Microsoft للمسارات الطويلة](https://learn.microsoft.com/en-us/windows/win32/fileio/maximum-file-path-limitation) صيغة المسار الممتد.

بقي تنسيق الجدول ومعالجة النص العربي والاستعلامات وقاعدة البيانات كما كانت. التعديل في خدمة التصدير، وليس في خدمة الجداول أو الاتصال بقاعدة البيانات.

أُضيف اختبار `tests/PdfExport` الذي يحمل ملفات التطبيق المنشورة في مجلد التشغيل الحقيقي، بدل الاعتماد على ملفات اختبار في مسار أقصر كان يخفي المشكلة.

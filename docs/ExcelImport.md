# استيراد التدريسيين والمواد من Excel

يكفي عمود «اسم التدريسي» وعمود «اسم المادة» (أو «المادة»). يمكن استيراد أحدهما منفرداً. لا يطلب المستورد مرحلة أو فصلاً أو تخصصاً أو معرفات، ويتجاهل الأعمدة الأخرى.

تُضاف الأسماء الجديدة إلى قائمتي التدريسيين والمواد، وتُتخطى الأسماء الموجودة أو المتكررة دون تعديلها. لا تنشأ تكليفات. تظهر المواد الجديدة باسمها ضمن «غير مصنفة»، بفصل غير محدد، ودون محاضرات أسبوعية. يمكن استكمال التفاصيل لاحقاً من شاشة المواد.

القالب يحتوي عمودي FacultyName وSubjectName فقط. الاستيراد يقبل .xlsx فقط، ولا يعرض مهام PDF أو الجدولة أو الإصلاح.

للتوافق مع قاعدة البيانات الحالية، تستخدم المادة غير المصنفة سجلاً محجوزاً بمعرف مرحلة 0؛ رقم الفصل المخزن 1 قيمة داخلية فقط ويعرض محرر المواد «غير محدد». أعداد المحاضرات صفر ولا تدخل المادة في التوليد قبل استكمالها. تُضاف مرحلة التصنيف المحجوزة ضمن معاملة الحفظ نفسها، ولا تظهر كمرحلة أكاديمية قابلة للاختيار في محرر المواد.

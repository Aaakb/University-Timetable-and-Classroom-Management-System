# استكمال وظائف الويب — 25 أكتوبر 2026

تعتمد الواجهتان على قاعدة البيانات وخدمات منطق العمل نفسها. استُكملت الفروق الوظيفية المكتشفة، مع واجهة ويب مستقلة عن تصميم Windows Forms.

## الوظائف المضافة

- **استيراد Excel / PDF** من القائمة الجانبية: رفع ملف `.xlsx` أو PDF نصي حتى 20 MB، اختيار الأوراق ونطاق الدراسة، وربط الأعمدة وتعديل الخلايا وتثبيت المحاضرات قبل التحقق. تُعرض البيانات على صفحات من 50 صفًا دون إسقاط بقية الصفوف.
- البيانات الأكاديمية، والتكليفات بالأسماء، والجدول الكامل، والجدولة مع توليد المتبقي، وإصلاح الجدول المستورد، تستخدم `ExcelImportService` نفسه. تتوفر قوالب Excel، وتحديث الموجود، وتخطي الصفوف الأكاديمية غير الصالحة، وتقارير الأخطاء والمقارنة قبل الإصلاح وبعده.
- الحفظ يعتمد المعاينة الموجودة على الخادم بعد تأكيد المستخدم؛ لا يعتمد بيانات جدول نهائي مرسلة من المتصفح. تغيير المدخلات يبطل المعاينة، وتغيير قاعدة البيانات يمنع اعتماد معاينة قديمة.
- **حفظ واستعادة الجدول**: تنزيل ملف JSON بنفس صيغة سطح المكتب، ومعاينة سلامته ومراجعه وعدد محاضرات الفصلين قبل تأكيد الاستعادة. تحفظ الخدمة نسخة أمان محلية قبل الاستبدال، ويظهر رابط لتنزيلها. يمكن استعادة ملف من أي من الواجهتين في الأخرى عند بقاء الموارد المرجعية متوافقة.
- **التثبيت اليدوي** في قائمتي الجدول العادي والأسبوعي. صفحة البدائل تدعم تثبيت مجموعة محاضرات وإلغاء تثبيتها، دون تغيير مواعيدها.
- **تفضيلات الأيام الاختيارية** أصبحت الصفحة الأساسية كما في نسخة Windows الحالية: مفضّل / مسموح / غير متاح، وحفظ التفضيلات مع تحسين جدول الفصل في عملية واحدة. يمكن إزالة الملف بالحفظ بدون تفضيلات، وتظهر التغييرات بعد الحفظ. تبقى مصفوفة الفترات في رابط متقدم منفصل.
- أضيف الفصل إلى محرر ومرشحات التكليفات. خُفّض تحميل القوائم المساعدة إلى الموارد التي تستخدمها الصفحة، مع تنفيذ الطلبات المستقلة معًا.

## حفظ البيانات وحدود التشغيل

الاستيراد والاستعادة وتفضيلات الأيام تستخدم المعاملات والتحقق الموجودين في الخدمات المشتركة. جلسات رفع الملفات والمعاينات محفوظة في ذاكرة الخادم لمدة 20 دقيقة وبملكية الحساب الذي أنشأها. ملفات الرفع المؤقتة تُحذف بعد القراءة. لا تُخزن ملفات المستخدم أو نتائج API في Service Worker أو localStorage.

تبقى نسخة الأمان قبل الاستعادة في `%LOCALAPPDATA%/UniversityTimetable/Backups` على جهاز الخادم. رابط تنزيلها من صفحة الويب صالح لمدة 20 دقيقة؛ انتهاء الرابط لا يحذف الملف المحلي.

PDF المصوّر يحتاج تحويلًا إلى نص قبل استيراده؛ لم تُضف OCR. يحد الرفع حجم الملف إلى 20 MB، ومحتوى Excel المفكوك إلى 100 MB، والنتيجة إلى 100 ورقة و500 ألف خلية. تتطلب الملفات الأكبر تقسيمها.

لا تغيّر هذه الإضافة سياسة الحسابات المشتركة: الحسابات المسجلة تملك صلاحيات الإدارة. كما يبقى قيد التزامن العام المذكور في دليل الويب عند تعديل السجل نفسه من سطح المكتب والويب معًا. هذه ليست مراجعة جاهزية للنشر العام أو اختبار ضغط واسعًا.

## التحقق

النتيجة النهائية: بناء الحل كاملًا دون أخطاء أو تحذيرات، ونجاح 131 فحص تكامل، و42 فحص متصفح دون أخطاء JavaScript، و43 فحصًا في قاعدة الويب المنفصلة. أكدت مقارنة السجلات بقاء بيانات الجامعة الأصلية دون تغيير بعد تنظيف اختبار التكامل.

```powershell
dotnet build tests/WebIntegration --no-restore
dotnet run --no-build --project UniversityTimetable.API --launch-profile local
# في نافذة أخرى؛ يتطلب --browser توفر Node وPlaywright وEdge:
dotnet run --no-build --project tests/WebIntegration -- --browser
dotnet run --project tests/WebDataTransfer
dotnet run --project tests/TimetableBackups
```

اختبار `WebIntegration` ينشئ سجلات مؤقتة مميزة وينظفها، ويقارن السجلات الأصلية قبل الاختبار وبعده. أُصلح تنظيف المواد المؤرشفة وتحديد overload مولد الجدول حتى يواكب الاختبار الكود الحالي. يشمل اختبار المتصفح التثبيت والاستيراد المعدل والحفظ وتنزيل النسخ ومعاينة الاستعادة وصفحات الأيام والبدائل، ومقاسات الجوال، والتثبيت كتطبيق، والعمل دون اتصال والعودة إليه.

اختبار `WebDataTransfer` ينشئ قاعدة SQL مؤقتة باسم فريد ويحذفها عند الانتهاء. يختبر الاستعادة الفعلية والرجوع من نسخة الأمان، وتفضيلات الأيام وتحديث الجدول، واستيراد PDF، والتوليد والإصلاح والحفظ، ورفض المعاينات القديمة ومعاينات حساب آخر. لا يستبدل جدول الجامعة الحقيقي.

نجحت أيضًا حالات خدمة النسخ الاحتياطي الـ13، بما فيها التراجع عند فشل الحفظ والإلغاء وفشل كتابة نسخة الأمان. فحوص قراءة PDF المشتركة الثمانية نجحت، ثم فشل اختبار تخطيط نافذة Windows القديمة بشرط `Preview too short` عند فحص نافذة الاستيراد؛ هذه نتيجة تخص تخطيط سطح المكتب، وليست فشل قارئ الملفات أو واجهة الويب.
